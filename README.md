# Тестовое задание Сенная Стор

## План
- Создаём простой TypeScript проект. Берём Vitest для тестов.
- Пишем минималистичный вариант функции под требования.
- Возвращаем обновлённую модель с записью в истории, без реализации хранилища.
- Покрываем тестами.

## Запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm test
npm run typecheck
```

`changeStatus(laptop, nextStatus, now?)` в `src/change-status.ts` возвращает
`{ ok: true, laptop }` или `{ ok: false, error }`. Исходный объект не изменяется.
Новый ноутбук: `{ status: "На складе", history: [] }`.

## Что было непонятно и как решили

14 дней — ровно 14 × 24 часа с последней продажи, граница включена.
Дату продажи берём из истории; при повторной продаже срок начинается заново.
Даты истории записываются в UTC (ISO 8601). Возврат без корректной даты продажи
или раньше продажи запрещён, переход в тот же статус — ошибка.
