# Тестовое задание Сенная Стор

## План
- Создаём простой TypeScript проект. Берём Vitest для тестов.
- Пишем минималистичный вариант функции под требования.
- Обновление модели и запись в историю делаем отдельными функциями, абстрагируя функционал который будет работать с хранилищами на проде.
- Покрываем тестами.

## Запуск

Нужен Node.js 22.12+.

```sh
npm ci
npm test
npm run typecheck
```

## Что было непонятно и как решили
